## Figure S2

Evolutionary and structural *in silico* properties measured for the native NS1 protein. Each row represents a different property, which are, in order, relative solvent accessible surface area (SASA RELATIVE), steric exclusion by glycan conformers (GLYCAN SHIELDING), number of major histocompatibility complex (MHC) class I predicted binding epitopes (MHC-I BINDERS), number of MHC class II predicted binding epitopes (MHC-II BINDERS), evolutionary conservation as measured by ConSurf (FAMILY-LEVEL CONSERVATION), changes identified through ancestral character reconstruction at each node of the YFV phylogeny (SPECIES-LEVEL CHANGES OVER TIME). Grey arrows indicate the known glycosylation sites.

## Table S3

Predicted MHC Class I and II binding epitopes identified using NetMHCpan and NetMHCIIpan. Positions (Pos) correspond to amino acid residue numbers within the NS1 protein sequence. "MHC" and "Locus" denote the predicted allele and dataset used by NetMHCIIpan, respectively. "Peptide" represents the full predicted epitope sequence, and "Core" indicates the minimal binding motif identified by NetMHCpan. The remaining parameters correspond to prediction metrics generated by NetMHCpan/NetMHCIIpan, including eluted ligand likelihood score (Score_EL), binding affinity score (Score_BA), percentile ranks (%Rank_EL and %Rank_BA), and predicted binding affinity in nanomolar units (Aff (nM)). Predicted binders were categorized as strong binders (SB) if they ranked within the top 0.5 % by Score_EL, and as weak binders (WB) if they ranked within the top 2% or 5% according to NetMHCpan and NetMHCIIpan, respectively.
